QUARK RUNTIME 0.2.0 — переносимый пакет защиты
================================================

Что внутри:

- quark-runtime.pdf   — слайды для показа. Открывается на любом ПК.
- quark-runtime.pptx  — та же презентация для PowerPoint. Текст доклада — в заметках к слайдам.
- quark-runtime.html  — та же презентация в одном файле, всё внутри.
- DEFENSE_SPEECH.docx — текст защиты: доклад, таблица ориентиров, ответы на вопросы.
- DEFENSE_SPEECH.md   — тот же текст в Markdown.
- README.txt          — эта инструкция.

Как показывать
--------------

Вариант 1. PDF (самый надёжный)
1. Скопируйте папку на флешку или откройте с неё.
2. Откройте quark-runtime.pdf в Adobe Reader, Edge или Chrome.
3. Включите полноэкранный режим: в Adobe — Ctrl+L, в браузере — F11.
4. В просмотрщике выставьте масштаб «По размеру страницы» / Fit Page.

Вариант 2. PowerPoint
1. Откройте quark-runtime.pptx в PowerPoint.
2. F5 — показ с первого слайда.
3. Если нужен текст доклада: вкладка «Вид» → «Заметки» или режим докладчика.
4. Слайды вставлены как изображения 1920×1080, поэтому вёрстка не поедет.

Вариант 3. HTML
1. Откройте quark-runtime.html в Chrome или Edge.
2. Стрелки влево/вправо, пробел, колесо мыши или свайп — переключение слайдов.
3. F — полный экран.
4. Home / End — первый / последний слайд.
5. quark-runtime.html#7 — сразу седьмой слайд.

Важно
-----
- Интернет не нужен: HTML не тянет шрифты и картинки из сети.
- FigCraft не нужен: .figcraft — только исходник для правок.
- PDF и HTML уже содержат актуальный слайд «Программная реализация: Rust + Tauri».
- Все цифры — ориентиры по классам железа, а не замеры конкретного ПК.
- В PPTX текст слайдов — часть изображения. Текст выступления лежит в заметках.

Исходник
--------
quark-runtime.figcraft — исходник в FigCraft, если нужны правки.
После правок PDF, HTML и PPTX пересобираются.
